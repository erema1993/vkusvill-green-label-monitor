# Монитор зелёных ценников ВкусВилла

Локальный прототип проверяет зелёные ценники выбранной в аккаунте корзины/магазина и отправляет в Telegram только товары, которых не было при предыдущей проверке.

## 1. Подготовка Telegram

1. Создайте бота у `@BotFather` и сохраните токен у себя.
2. Напишите созданному боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` и возьмите число из `message.chat.id`.

## 2. Локальные секреты

В папке проекта сделайте копию `.env.example` с именем `.env`. Вставьте туда:

- `VV_COOKIE` — только содержимое Cookie из рабочего запроса, без `-b` и внешних кавычек;
- `TELEGRAM_BOT_TOKEN`;
- `TELEGRAM_CHAT_ID`.

Файл `.env` исключён из Git. Не отправляйте его в чат и не публикуйте.

## 3. Проверка

```bash
python3 -m unittest -v
python3 monitor.py --dry-run
python3 monitor.py --send-test
python3 monitor.py
```

Первый обычный запуск запоминает текущие товары и ничего о них не отправляет. Последующие запуски уведомляют только о новых `data-id`. Для повторной чистой проверки удалите `state.json` вручную.

Важно: выбранный магазин хранится в сессии ВкусВилла. Перед копированием Cookie убедитесь на сайте, что корзина привязана к нужному адресу. Cookies со временем истекают — тогда потребуется обновить `VV_COOKIE`.

## Облачный запуск

GitHub Actions запускает `monitor.py` каждые 10 минут по файлу `.github/workflows/monitor.yml`. Cookies и параметры Telegram хранятся только в GitHub Actions Secrets. Текущий список товаров сохраняется в Actions cache только в виде HMAC-хешей; первый облачный запуск создаёт базу без уведомлений обо всех старых товарах.

Запланированные workflow публичного репозитория GitHub автоматически отключаются после 60 дней без активности. В таком случае откройте вкладку Actions и включите workflow снова.
